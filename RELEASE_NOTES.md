## New

- **Update pop-up**: when a new version is out, the app says so in a window when it opens, with **Update now**,
  **Later** and **What's new**. It never opens over a running game: it waits until the game is closed.
- **News without updating**: short notices published on GitHub (a patch that changed a camp, a new feature) show
  up once in the app, in your language.

## Changed

- The repository is reorganized: the app's code now lives in `src/`.

1.0.3 updates itself: click **Update to version 1.0.4** in the overlay or the tray icon. Older versions: run this
installer over them once. Your PBs are kept.
